# GitHub Upload Checklist

- [ ] Replace profile README placeholders with your actual GitHub username and LinkedIn URL (if you want to share it).
- [ ] Run `python app.py` and test create/save/update/delete/search/Markdown preview.
- [ ] Capture genuine screenshots of the running application and add them to the README.
- [ ] Do not upload `research_notes.db`, personal data, API keys, passwords, or private documents.
- [ ] This GitHub-ready package intentionally excludes the original `images/` directory because Part 1 does not use it; it contained unrelated image files, including a WhatsApp-named image.
- [ ] Create a public repository named `research-paper-organizer` if you want universities/admissions reviewers to see it.
- [ ] Upload only the clean project files, not the ZIP itself as the repository contents.
- [ ] Add a license only if you have decided how you want others to reuse the code.
